Phone

Control the light from your iPhone over Bluetooth. The phone stays on its normal Wi-Fi.

Phone control needs the bridge to be connected.
Set up an iPhone
  1. Install BluefyA free web browser with Bluetooth, from the App Store. Safari can't use Bluetooth.
  2. Open the phone page in BluefyType this address in Bluefy's address bar and save it as a favourite:
    —
  3. PairPress Pair a phone below, then in Bluefy tap Connect, choose Lamp and type the PIN when iOS asks.
